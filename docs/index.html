Features

为什么选择 S-Hy2？

从零到生产环境，一条命令搞定

真正一键部署

7 步自动完成：域名检测、密码生成、证书申请、配置生成、端口跳跃、服务启动。

安全优先设计

输入注入防护、SHA256 完整性校验、TLS 1.2+ 强制、安全临时文件、白名单删除。

双模式操作

交互式菜单适合新手学习，CLI 参数适合自动化脚本和定时任务。

智能伪装域名

自动测试 30+ 热门域名延迟，DNS 验证 + 结果缓存，一键选择最优伪装。

多用户管理

单密码 / 多用户模式切换，批量添加 1-100 用户，自动生成 16 位强密码。

多客户端导出

一键生成 Hysteria2、Clash、SingBox 配置，URI 链接、二维码、订阅地址。

Install

一键安装

支持 Ubuntu / Debian / CentOS / Fedora，一条命令部署

终端
$ curl -fsSL --proto '=https' --tlsv1.2 -o quick-install.sh \
  https://raw.githubusercontent.com/.../quick-install.sh
$ bash -n quick-install.sh # 语法校验
$ sudo bash quick-install.sh
$ sudo s-hy2 # 启动管理菜单
$ curl -fsSL --proto '=https' --tlsv1.2 -o quick-install.sh https://raw.githubusercontent.com/motao123/S-Hy2-Manager/main/quick-install.sh && bash -n quick-install.sh && sudo bash quick-install.sh
s-hy2交互菜单
s-hy2 --install安装 Hy2
s-hy2 --status查看状态
s-hy2 --restart重启服务
s-hy2 --export导出配置
s-hy2 --list-users用户列表
s-hy2 --backup备份配置
s-hy2 --speed-test速度测试
