Features

核心特性

安全、高效、易用 — 从零到生产一条命令搞定

⚡

真正一键部署

7 步自动完成：域名检测、密码生成、证书申请、配置生成、端口跳跃、服务启动。部署后自动执行 8 项验证，发现问题自动修复。

🔒

安全优先

输入注入防护、SHA256 校验、TLS 1.2+、安全临时文件、白名单删除。

🖥

双模式

交互式菜单新手友好，CLI 参数适合自动化脚本和定时任务。

🌐

智能伪装

并发测试 30+ 域名延迟，DNS 验证 + 缓存，自动选择最优伪装。

👥

多用户

单密码 / 多用户切换，批量添加 1-100 用户，自动生成强密码。

📦

客户端导出

Hysteria2、Clash、SingBox 配置一键生成，URI、二维码、订阅。
