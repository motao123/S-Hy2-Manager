核心特性

从零到生产环境，一条命令搞定

⚡

真正一键部署

7 步自动完成：域名检测、密码生成、证书申请、配置生成、端口跳跃、服务启动。部署后 8 项自动验证。

🔒

安全优先设计

输入注入防护、SHA256 完整性校验、TLS 1.2+ 强制、安全临时文件、白名单删除、脚本语法预检。

🖥

双模式操作

交互式菜单适合新手探索，CLI 参数适合自动化和定时任务。21 个菜单项 + 18 个 CLI 命令。

🌐

智能伪装域名

并发测试 30+ 热门域名延迟，DNS 验证 + 结果缓存 1 小时，自动选择最优伪装目标。

👥

多用户管理

单密码 / 多用户模式切换，批量添加 1-100 用户，自动生成 16 位强密码，CLI 快捷操作。

📦

多客户端导出

一键生成 Hysteria2、Clash、SingBox 配置，URI 链接、二维码、Base64 订阅、Nginx 托管订阅。

一键安装

支持 Ubuntu / Debian / CentOS / Fedora

install
$ curl -fsSL --proto '=https' --tlsv1.2 \
  -o quick-install.sh https://raw.githubusercontent.com/
  motao123/S-Hy2-Manager/main/quick-install.sh
$ bash -n quick-install.sh # 语法校验
$ sudo bash quick-install.sh
$ sudo s-hy2
curl -fsSL --proto '=https' --tlsv1.2 -o s.sh https://raw.githubusercontent.com/motao123/S-Hy2-Manager/main/quick-install.sh && bash -n s.sh && sudo bash s.sh
